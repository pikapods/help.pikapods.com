---
title: Manage Your Pods
description: Learn how to manage custom domains, files, databases, backups and access restrictions for your PikaPods pods.
---

Everything you can do with a pod after it's running:

- [Getting Started](/manage/getting-started): Create an account and run your first app.
- [Custom Domains](/manage/custom-domains): Make a pod available under your own domain name.
- [Access Files (SFTP)](/manage/files): Upload, download and edit a pod's files.
- [Database Access](/manage/database): View, edit, import or export an app's database.
- [Backups](/manage/backup): Set up automatic backups to storage you control.
- [Troubleshooting](/manage/debug): Check logs and fix a pod that won't start.
- [Firewall](/manage/firewall): Only allow selected IP addresses to reach a pod.
